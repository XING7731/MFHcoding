# 01 - 巴法云配置（TCP 创客云）

巴法云（bemfa.com）的 TCP 创客云是免费、最简单的接入方式，设备通过原始 TCP 连接收发字符串。

## 1. 注册并获取私钥

1. 打开 <https://bemfa.com> 注册账号（邮箱注册即可）。
2. 登录后进入 **控制台**，页面顶部可以看到你的 **私钥（uid）**，一串字母数字。
3. 把私钥填到工程的 `user/user_config.h`：


   ```c
   #define BEMFA_UID   "你的私钥"
   ```

## 2. 创建主题

1. 控制台 → **TCP 创客云** → 添加主题。
2. 主题名输入 `temp001`（TCP 创客云的主题名建议以 `001` 结尾）。
3. 填到工程里：
   ```c
   #define BEMFA_TOPIC "temp001"
   ```

## 3. 主题消息格式

设备每 6 秒上传一条消息，格式为 `温度,湿度`，例如：

```
25.6,60
```

- 在控制台的主题详情页可以实时看到收到的消息。
- 想用巴法云小程序/App 查看数据，可在控制台绑定，主题消息同样可见。

## 4. 协议速查（本工程已在 esp8266.c 中封装好）

| 动作 | 发送内容（TCP 明文）                                 |
| -- | -------------------------------------------- |
| 订阅 | `cmd=1&uid=私钥&topic=temp001\r\n`             |
| 发布 | `cmd=2&uid=私钥&topic=temp001&msg=25.6,60\r\n` |
| 心跳 | `ping\r\n`（30 秒内至少一次，否则服务器主动断开）              |

服务器地址：`bemfa.com`，端口：`8344`。

## 5. 下行控制（可选扩展）

给主题发消息时，设备会收到 `cmd=2&uid=...&msg=xxx` 的下发数据。  
如需远程控制（如继电器），在 `ESP8266_Poll()` 中解析环形缓冲区里的 `&msg=` 内容即可，以后可以扩展。
