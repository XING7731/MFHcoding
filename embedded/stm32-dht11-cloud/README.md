# STM32F103C8T6 环境温湿度上云（DHT11 + ESP8266 + 巴法云）

STM32 每隔 6 秒读取 DHT11 温湿度，通过 ESP8266-01S 连接 WiFi，把 `温度,湿度`
上传到巴法云 TCP 创客云，网页/小程序实时查看；每 25 秒发一次心跳保活，断线自动重连。

## 硬件清单

| 器件 | 数量 | 说明 |
|------|------|------|
| STM32F103C8T6 最小系统板（Blue Pill） | 1 | |
| DHT11 温湿度传感器模块 | 1 | 数据线需 4.7K~10K 上拉（模块一般已自带） |
| ESP8266-01S WiFi 模块 | 1 | **必须独立 3.3V 供电，≥300mA** |
| AMS1117-3.3 稳压模块 | 1 | 给 ESP8266 供电（5V 转 3.3V） |
| USB-TTL 串口模块 | 1 | 可选，看调试日志（PA2/PA3） |
| ST-Link / 串口 ISP | 1 | 烧录用 |

## 接线

| STM32 | 连接 |
|-------|------|
| PA1 | DHT11 DATA（VCC-3.3V，GND 共地，DATA 上拉 4.7K~10K） |
| PA9 (USART1_TX) | ESP8266 RX |
| PA10 (USART1_RX) | ESP8266 TX |
| PA2 (USART2_TX) | USB-TTL RX（调试） |
| PA3 (USART2_RX) | USB-TTL TX（调试） |
| 3.3V / GND | 各器件供电，共地 |

⚠️ 三个坑（新手 90% 卡在这里）：
1. **ESP8266 供电**：从开发板 3.3V 直接取电大概率启动失败/连接中断，务必用独立 3.3V（AMS1117 或独立电源），且与 STM32 共地。
2. **DHT11 上拉**：裸传感器必须 DATA 上拉；市售模块一般已板上自带。
3. **共地**：所有器件 GND 必须连在一起。

## 上手步骤（5 步）

1. 按 `docs/02-CubeMX配置指南.md` 在 CubeMX 里配置并生成 Keil 工程（5 分钟）。
2. Keil 中添加 `user/Src` 的 3 个 .c 文件和 `user/Inc` 头文件路径。
3. 按 `user/Src/main.c` 文件头的说明，把主逻辑合入（或整文件替换）。
4. 修改 `user/Inc/user_config.h`：WiFi 名称/密码、巴法云私钥、主题名。
5. 编译烧录，打开串口助手（115200）看日志，到巴法云控制台看数据。

## 常见问题

| 现象 | 排查 |
|------|------|
| `AT` 无应答 | ESP8266 供电不足；TX/RX 接反；出厂波特率若是 9600，把 USART1 改成 9600 |
| WiFi 连不上 | SSID/密码错误；**WiFi 必须是 2.4GHz**，5GHz 连不上 |
| DHT11 读失败 | 检查上拉电阻、接线、供电 3.3V；读取间隔别小于 2 秒 |
| 上传后控制台没消息 | 私钥/主题名填错；`temp001` 主题没在控制台创建 |
| 频繁断线 | 心跳周期必须 <30 秒；网络不稳会自动重连，属正常 |
