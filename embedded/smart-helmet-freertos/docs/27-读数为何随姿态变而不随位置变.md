# 27 · 读数为什么随"姿态"变、却完全不随"位置"变

> 触发问题：**"你说测得是加速度，那我把传感器换一个位置怎么读数变化之后保持不变了？"**
>
> 这篇文档不讨论代码，只回答一个物理问题。因为这个问题反复出现了三次
> （见 docs/25、docs/26），说明它靠"解释"是说不透的，必须给**可自证的实验**。

---

## 1. 一句话结论

**读数跟踪的是姿态（朝向），不是位置（在哪）。**

"换一个位置"这个动作里，实际上混了两件不同的事：

| 你做的动作 | 是否影响读数 |
|---|---|
| **平移** —— 把板子从桌上挪到椅子上，朝向不变 | **完全不影响**。读数一个数字都不动 |
| **旋转** —— 板子转了个角度 | **直接影响**。三轴读数全部重新分配 |

日常动作里这两件事几乎总是同时发生（人手挪东西必然带旋转），
所以看起来像"位置一变读数就变"。**必须把两者拆开单独做，结论才显形。**

---

## 2. 物理原因：重力矢量恒定，变的是它在各轴上的投影

加速度计测的是**比力**（specific force）。静止时板子受到的比力 = 地板/桌面
把它顶住的 1g 反作用力，方向竖直向上（读数体系里表现为"重力方向"）。

关键有三条：

1. 这根矢量的**长度恒为 1g**，**方向恒指向地心**——无论板子怎么摆、放到哪；
2. 板子转动 → 传感器的三个测量轴跟着转 → 同一根矢量在 x/y/z 上的**分量重新分家**；
3. 板子平移 → 三个轴**没有转** → 分量分毫不动。

所以读数 = `重力矢量 · 板子的某个轴`，只跟"轴指向哪"有关。

### 2.1 定量：要把读数变多少，就得转多少

设 x 轴与重力方向的夹角为 θ，则 `ax = 1.0 × cosθ`：

| 倾角 θ | ax 理论值 | 显示（1 位小数） |
|---|---|---|
| 0° | 1.000 | 1.0 |
| 10° | 0.985 | 1.0 |
| 20° | 0.940 | 0.9 |
| 30° | 0.866 | 0.9 |
| 45° | 0.707 | 0.7 |
| 60° | 0.500 | 0.5 |
| 90° | 0.000 | 0.0 |

**这张表能反过来给动作"定性"**：小角度倾斜对读数的影响是**二阶小量**
（cos 曲线在 0° 处是平的），转 10° 读数几乎不变。所以——

> 只要读数出现了肉眼可见的变化（比如从 1.0 变成 0.7），
> 板子的**朝向必然已经转了很大的角度**（≥45°），不可能是"只挪了个位置"。

---

## 3. 三个判决实验（自己动手，一次定性）

按顺序做，每个都能单独回答"它到底测什么"：

| 操作 | 预期读数 | 结论 |
|---|---|---|
| ① **端着板子在房间里边走边挪，手上不转** | 全程 `1.0 0.0 0.0` 纹丝不动 | 位置变了、读数没变 → **不是位置传感器** |
| ② **停在原地，把它转 180°** | 该轴 `+1.0 → −1.0`（符号翻转） | 只有朝向能改读数 → 读的是**重力投影** |
| ③ **松手让它自由下落**（手在下面接着） | 短暂掉到 ≈ `0.0` | 位置量**不可能**读到 0 → 只有惯性量会归零 |

补充第 ④ 个（不用动手就能做）：**看模值 `|a|`**。
任意姿态下静止，屏幕 A 行末尾的 `|a|` 都应当 ≈ `1.0`。
位置量在任意姿态下恒定不变是说不过去的——位置是个可以任意取值的量。

### 3.1 关于"变化之后保持不变"

这其实是**两个阶段的叠加**，很容易被误读成一个现象：

| 阶段 | 现象 | 物理含义 |
|---|---|---|
| 手正在动的过程中 | 数字乱跳 | 这段时间读的**确实是加速度**：手甩动的加减速、撞击、抖动 |
| 停稳之后 | 定在一个新的值不动 | 手不动了 → 真实加速度 = 0 → 只剩重力投影这一个静态分量 |

**"停稳后读数不为 0"恰恰是加速度计最标准的特征**，不是位置证据：
加速度计测比力，你静置在桌上，桌子用 1g 的力顶住你，它就报 1g。
真正为 0 的时刻只有自由落体（实验③）。

## 4. 硬件层面的旁证

MPU6050 的寄存器映射里**根本不存在"位置/坐标"这一类寄存器**：

| 地址 | 内容 |
|---|---|
| `0x3B` ~ `0x40` | `ACCEL_XOUT_H/L`、`YOUT`、`ZOUT` —— 三轴**加速度** |
| `0x41` ~ `0x42` | `TEMP_OUT` —— 温度 |
| `0x43` ~ `0x48` | `GYRO_XOUT`… —— 三轴**角速度** |
| `0x75` | `WHO_AM_I` |

没有位置寄存器，也没有任何解算逻辑能凭空造出位置：从加速度积分两次可得到
位移，但误差随时间**平方级发散**（静置几分钟就能漂几十米），工程上不可用。
这也是本工程 `docs/03-传感器接口与限制说明.md` 写明"不做姿态解算、无 DMP、
无卡尔曼滤波"的原因——姿态角虽然可以由加速度反算（见下），但航向角
（yaw / 朝向哪个方位）需要磁力计，现有硬件做不到。

### 4.1 反过来说：姿态角是可以算的，而且是从加速度算的

如果哪天想在小程序或 OLED 上直接显示倾角，公式是纯几何的：

```
pitch = atan2(ax, sqrt(ay*ay + az*az)) × 57.3   度
roll  = atan2(ay, sqrt(ax*ax + az*az)) × 57.3   度
```

注意它的输入是**加速度**——能算出一个角度，不等于这些数字本身是角度。

**额外收益**：这个算式对 docs/25 里那个"克隆片读数放大 4 倍"的问题**天然免疫**
——分子分母同时放大，比值不变。所以在量程没修好时算出的倾角依然是准的。

## 5. 与本工程摔倒判据的关系

判据用 `|a|`（三轴模值）而不是单轴读数，正是因为上面第 2 条：

- 静止 / 正常佩戴 → `|a| ≈ 1.0g`（**与帽子朝哪个方向无关**）
- 失重下坠 → `|a|` 掉向 0
- 撞击 → `|a|` 冲到 1.8g 以上
- 摔后躺地不动 → `|a|` 又回到 1.0g

如果三轴读数真像"位置"那样随摆放乱变，模值判据根本不成立。
所以"判据只用模值"这一设计本身，就是"它测的是加速度"的又一个证据。

---

## 6. 万一实验①真的让读数变了

如果**严格只平移、完全不转**，读数却变了并停在新的值上，那说明问题不在物理，
而在下面几类，按顺序排查：

| 可能原因 | 现场判别 |
|---|---|
| 手上其实带了旋转（最常见） | 重做实验①，眼睛盯着板子的边线别歪；对照 §2.1，读数变化 ≥0.2 就说明转过 ≥30° |
| `ACCEL_CONFIG` 被运行期改动（量程变了、灵敏度变了） | 看屏幕 A 行的 `|a|` 是否还在 1.0；变了就重启让自标定重跑 |
| I2C 偶发读错 / 样本被丢 | 数值是否**跳变**而非平滑过渡；配合串口日志看 `mpu_ok` |
| 板子固定不牢、线缆把板子带歪了 | 拔掉线缆单独手持重做 |
| 器件真的坏了 | 做实验③：自由落体都读不出 0，就该换片 |

---

## 7. 一句话总结

> **加速度计跟踪的是"板子朝哪转"，不是"板子在哪"。**
> 静止时那根 1g 的重力矢量一直在，只是它分给 x/y/z 各多少，取决于板子的姿态。
> 想验证就做三个动作：**平移不转（读数不变）、原地转向（读数翻转）、自由落体（读数归零）**。
