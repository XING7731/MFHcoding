# 14 - I2C 共用总线与心率模块接线（"引脚重复"到底是不是问题）

> 结论先行：**OLED 和 MAX30102 接在同一对引脚（PB6/PB7）上不是冲突，这是 I2C 的正常用法。**
> 本文说明为什么不是冲突、你这个 7 脚模块该怎么接，以及上电自检屏怎么读。

---

## 一、为什么"同一个引脚"不等于"冲突"

I2C 是**总线**结构：一根 SCL（时钟）+ 一根 SDA（数据），
所有器件**并联**挂在这两根线上，谁都不需要单独的片选线。

主机的通信过程是"点名"：

```
主机: [地址 0x57] + [寄存器地址] + [数据]      ← 只有 0x57 会应答
主机: [地址 0x3C] + [命令/数据]               ← 只有 0x3C 会应答
```

没被点名的器件在这段时间里**保持沉默（高阻）**，不参与通信。
所以只要**地址互不相同**，挂多少个器件都行。

本工程的三个 I2C 器件：

| 器件 | 7 位地址 | 来源 |
|---|---|---|
| OLED SSD1306 | `0x3C` | `user_config.h` → `OLED_I2C_ADDR7` |
| MPU6050（六轴） | `0x68` | `MPU6050_I2C_ADDR7`（AD0 接 GND） |
| MAX30102（心率/血氧） | `0x57` | `MAX30102_I2C_ADDR7` |

三个地址互不相同 → **不冲突**。

---

## 二、你这个模块怎么接（7 脚 MAX30102）

你的模块丝印是 `VIN / GND / SCL / SDA / INT / IRD / RD`，属于常见的
MAX30102 心率血氧模块。**只需要接 4 根线**：

| 模块引脚 | 接到 | 说明 |
|---|---|---|
| **VIN** | 3.3V | 不要接 5V |
| **GND** | GND | 与 MCU **共地** |
| **SCL** | **PB6** | 与 OLED 的 SCL 接在同一根线上（**并联**） |
| **SDA** | **PB7** | 与 OLED 的 SDA 接在同一根线上（**并联**） |
| **INT** | 不接 | 固件用轮询方式读 FIFO，不用中断 |
| **IRD** | 不接 | 片上 LED 的引出脚，本工程不使用 |
| **RD** | 不接 | 同上 |

OLED 的模块引脚（通常是 `GND / VCC / SCL / SDA`）：

| 模块引脚 | 接到 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SCL | **PB6**（和 MAX30102 的 SCL 拧在一起） |
| SDA | **PB7**（和 MAX30102 的 SDA 拧在一起） |

**接线图（面包板/杜邦线的实际接法）**

```
        3.3V ──┬──────────────┬──────────────┐
               │              │              │
             OLED.VCC    MAX30102.VIN   (I2C 上拉 4.7K ×2)
                                            │
  PB6 (SCL) ───┼──────────────┼─────────────┘
             OLED.SCL    MAX30102.SCL
                                            │
  PB7 (SDA) ───┼──────────────┼─────────────┘
             OLED.SDA    MAX30102.SDA
               │              │
  GND ─────────┴──────────────┘
```

一句话：**同一个节点上出现两根线，是"并联"，不是"打架"。**

### 上拉电阻：只加一次

I2C 靠上拉电阻把线拉高，**整条总线只需要一组**（PB6↔3.3V、PB7↔3.3V 各 4.7K）。

- OLED 模块**通常板上已带** 4.7K，那就**不要再给 MAX30102 加**——两者并联会变成约 2.35K，虽然多数情况仍能用，但没必要。
- 如果两个模块都不带上拉，就必须自己加一组。
- **不要给每个模块各加一组**：并起来阻值过低，总线反而可能拉不动。

## 三、上电自检屏：怎么确认"三个器件都在线上"

从本版固件起，**上电时会扫一遍 I2C 总线并把结果写在屏幕上**
（`main.c` 的 `I2C_BusScan()` / `I2C_ScanShowOnOled()`），
停留约 3.5 秒后交还给正常显示。无需 USB-TTL，**按一下复位键就能看**。

```
┌──────────────────────┐
│ SMART HELMET         │
│ I2C: 3C 57 68        │   ← 总线上所有应答的地址
│ O:OK M:OK X:OK       │   ← O=OLED  M=MPU6050  X=心率(MAX30102)
│ PB6=SCL PB7=SDA      │
│ MAX30102 OK          │   ← 心率芯片的单独结论
└──────────────────────┘
```

### 判读表

| 屏幕内容 | 含义 | 下一步 |
|---|---|---|
| `O:OK M:OK X:OK` + `MAX30102 OK` | 三个器件都在总线上，**引脚无冲突** | 正常 |
| `X:--` + `MAX30102 NOT ON BUS` | 心率芯片**没有应答**，压根没在线 | 查 VIN/GND 供电、SCL/SDA 是否接到 PB6/PB7、线是否断 |
| `X:OK` + `MAX30102 ID ERR 3` | 地址应答了但 **PART_ID 不是 0x15** | 买到了非 MAX30102 的兼容片，或模块异常 |
| `O:--` 且屏幕**完全不亮** | OLED 没应答 | 屏幕没接好，或整条总线被某个器件拉死（见下节） |
| `I2C:` 后面**一个地址都没有** | 总线上没有任何器件应答 | PB6/PB7 接错线/没供电/没有上拉 |

同一份结果也会打到调试串口（USART2，115200）：

```
[BOOT] I2C bus scan
[I2C] found 3: 3C 57 68
[BOOT] MAX30102 OK
```

### 正常运行时也会提示

如果心率芯片不在总线上，正常显示界面的第 2 行（心率行）会显示：

```
SPO2:MAX30102 NG
```

这与 `HR:-- SpO2:--`（器件在，只是没放手指 / 还没预热完）是**两种不同情况**，
一眼就能区分，不必再往算法上找原因。

另外三个状态也会分别显示：`PPG warming up`（器件在线但样本还没进来）、
`HR:-- SpO2:--`（有样本但算不出心率，此时看第 6 行的 `PPG d:.. a:..`）、
`HR:xx SpO2:--`（正常）。**器件在线却读不出心率**的分级判读见
**`docs/15-心率无读数排查.md`**。

## 四、真正会出问题的两种情况

### 1. 某个器件把 SDA 拉死在低电平 → 整条总线瘫痪

现象很有迷惑性：**连 OLED 都黑屏**，看起来特别像"引脚打架"。

原因：I2C 是线与结构，只要有一个器件把 SDA 死死拉低，
**所有**通信都会失败。

**定位办法**：断电，只留 OLED（拔掉 MPU6050 和 MAX30102 的 SCL/SDA），
上电看自检屏。

- 只留 OLED 时 `O:OK`，插回某个模块后 `O:--` → 就是这个模块在拖总线。

### 2. 你的模块根本不是 I2C 的 → 这才是真冲突

| 模块类型 | 引脚特征 | 处理 |
|---|---|---|
| I2C 型（本工程适用） | `VIN/GND/SCL/SDA` | 并联到 PB6/PB7，无需改代码 |
| **模拟输出型**（如 Pulse Sensor） | `VCC/GND/SIG` 3 脚，输出模拟电压 | **要占一个 ADC 引脚**（如 PA0），并改驱动 |
| **SPI 型** | 有 `D0/D1/RES/DC/CS` 或 `MOSI/MISO/SCK/CS` | 要单独分配 SPI 引脚，并改驱动 |

**你是怎么判断的**：模块上写着 `SCL`/`SDA` 就是 I2C；
写着 `SIG`/`AO` 是模拟输出；有一堆 `CS`/`RES`/`DC` 的是 SPI。

## 五、快速自查

- [ ] 心率模块只接了 `VIN / GND / SCL / SDA` 四根线，`INT / IRD / RD` 悬空
- [ ] SCL 接 **PB6**、SDA 接 **PB7**（**不是**接反，也不是接 PB8/PB9）
- [ ] 心率模块与 OLED 的 SCL 接在**同一个节点**、SDA 接在**同一个节点**
- [ ] 上拉电阻只有一组（4.7K ×2），没有重复叠加
- [ ] 所有模块与 MCU **共地**
- [ ] VIN 接 **3.3V**（不是 5V）
- [ ] 上电后自检屏显示 `X:OK`
