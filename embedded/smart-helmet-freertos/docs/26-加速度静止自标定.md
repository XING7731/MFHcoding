# 26 · 加速度静止自标定（把读数修成真实 g）

> 2026-09-16 · 起因：现场提出"你这个 xyz 加速度是 xyz 轴相对位置吧，怎么当加速度了"
>
> 复查结果：**它确实是加速度计，但上一版的读数确实是错的** —— 被整体放大 4 倍。
> 本版不再靠"调阈值迁就错误读数"，改用一条物理定律把读数直接标定成真实 g。

---

## 1. 先回答那个问题：加速度计测的是什么

MPU6050 的 `ACCEL_XOUT_H(0x3B)` 起输出的是**加速度**，单位 g。驱动 `mpu6050.c`
里那一步换算就是全部：

```c
d->ax = (float)ax / s_accel_lsb_per_g;    /* 原始码值 ÷ 灵敏度 = 多少 g */
```

**那为什么静止不动不是 0，而是有读数？**

因为加速度计测的是**比力** —— 帽子躺在地面/桌面上，它读到的是支撑面顶回来的 1g
反作用力，方向朝上。重力矢量**永远指向地心、长度永远是 1g**，板子怎么转，改变的
只是"这 1g 分到 x/y/z 各轴上有多少"。

所以"静止时 x 轴恒为某个值"这个观察本身是对的：它说明 **x 轴正竖直朝下**，重力
全落在这一个轴上。它确实携带朝向信息 —— 但量纲是加速度，不是位移。

| | 三轴加速度 | 位置 / 位移 |
|---|---|---|
| 能否直接测 | **能**，就是它 | 不能 |
| 怎么得到 | 直接读寄存器 | 要对加速度二次积分，误差平方级发散 |
| 有无绝对参考 | 有（重力方向恒定 1g） | 无 |
| 实测后果 | 测倾角很稳 | 静置几分钟漂几十米 |
| 绕重力轴旋转（航向/yaw） | **测不到**（需磁力计） | —— |

**一条判据就能分开这两者：静止时三轴模值 `|a| = √(ax²+ay²+az²)` 恒为 1.0g，
与姿态无关。** 位置量不可能在任意姿态下都给出同一个固定模值。

也正因为模值恒定（静止 1g / 失重→0 / 撞击数 g），摔倒判据只用 `|a|` 才成立。

---

## 2. 上一版方案错在哪（以及为什么"改对了又不完全对"）

现场现象：静止时 `A:3.9 0.0 0.0`，x 轴恒定 3.9。

根因（见 `docs/22`、`docs/25`）：这颗 MPU6050 克隆片**把 `ACCEL_CONFIG` 连读回都
伪造成了 ±8g**，但内部灵敏度仍锁在 ±2g 的 16384 LSB/g。驱动按 ±8g 的 4096 LSB/g
解码 → 所有读数 ×4。

上一版的应对是把阈值一起放大（`2.5 → 5.0`，`1.5 → 4.5`），让判据在"放大 4 倍的
读数体系"里继续工作。**这能跑，但代价有三**：

1. 阈值从此不对应需求文档的物理值，验收/复现时无法自圆其说；
2. 稳定窗口被压成 `5.0~4.5`（宽 0.5g），摔后稍有晃动就反复重置计时；
3. 参数绑死在"这一批片子的错误"上 —— 换一片量程正常的芯片，同一份固件读数又不准。

**问题的本质是：读数错了，却拿阈值去迁就，而不是把读数修对。**

---

## 3. 本版方案：静止自标定

所依据的物理事实只有一条：

```
静止时重力矢量长度恒为 1g   →   |a| ≡ 1g  （与姿态无关）
```

于是：

```
        码值模值 / 真实LSB/g = 1g
    ⇒   真实LSB/g = 码值模值
```

**做法**：上电时把静止期间读到的**原始码值**（未经换算）取模值、求平均，这个均值
**就是**芯片真实的 LSB/g。

**关键点：全程不读任何寄存器。** 芯片把 `ACCEL_CONFIG` 伪造成 ±8g 也没用 —— 它
改变不了"静止时模值对应 1g"。这正是本方案与读写回校验的本质区别：

| | 查的是什么 | 克隆片能否骗过 |
|---|---|---|
| 读写回校验（上一版） | 寄存器说的，和写进去的一致吗？ | **能**（实测已被骗过） |
| 静止自标定（本版） | 读数和物理定律一致吗？ | **不能** |

### 3.1 怎么判断"这段时间真的静止"

动着的样本算出的均值没有物理意义，必须整轮丢弃重来。判据是**极差占均值的百分比**：

- `≤ 6%` → 认为静止，接受本轮；
- `> 6%` → 丢弃本轮，间隔 250ms 后重来，最多 4 轮；
- 4 轮全失败 → **回退**到寄存器读回推算值，并置 `cal_ok = 0`。

再加一条合理性检查：标定值必须落在 `500 ~ 40000 LSB/g`（覆盖 ±16g 到 ±2g 且各有
数倍余量）。**少了这一条，一个坏传感器输出的乱数也可能"碰巧很稳定"。**

## 4. 数值验证（`tools/accel_cal_sim.py`）

烧录前先在 PC 上把推导走一遍：

```
① 静止标定
  真实灵敏度(物理)   :  16384.0 LSB/g    (= ±2g 档)
  寄存器读回假设值   :   4096.0 LSB/g    (= ±8g 档, 芯片在撒谎)
  静止标定测得       :  16387.7 LSB/g
  相对误差           :     0.02 %        ← 标定值 = 真实值

② 同一批码值，两种换算系数
     真实加速度   原始码值   旧:÷4096   新:÷16384
        1.00g      16384      4.00g       1.00g   ← 旧的 3.9 就是这么来的
        6.00g      32767      8.00g       2.00g   ← 被 int16 削顶

③ 摔倒判据 |a|>1.8g 两次 + 1.5s 内 <1.5g
  标定成功(÷16384):  静止 1.00g  冲击 2.00g  →  三条件全过，可触发
  标定失败(÷4096) :  静止 4.00g  冲击 8.00g  →  条件3 恒不成立，永不触发

④ 量程上限决定 HIGH 能取多大
  ±2g 档读数上限 = 32767 / 16384 = 2.00g
    HIGH = 1.8g  →  可触发
    HIGH = 2.0g  →  永不触发（2.00 <= 2.0）
    HIGH = 2.5g  →  永不触发（需求原值，物理不可达）
```

第 ③ 行是**必须看懂的一行**：标定失败时读数停在放大状态，静止就有 4.0g > 阈值
1.8g，状态机长期卡在 `IMPACT` 出不来，而条件3 又因 4.0 永不小于 1.5 而不成立 ——
**真摔也不报警**。所以标定失败必须让人看见（屏幕 `! ACAL FAIL`）。

## 5. 代码改动

### 5.1 `user/Src/mpu6050.c` / `user/Inc/mpu6050.h`

| 新增 | 作用 |
|---|---|
| `read_raw_accel()` | 读三轴**原始码值**。标定必须用原始值 —— 一旦经过 `s_accel_lsb_per_g` 换算，求出的均值就不是 LSB/g 了（用要标定的系数去标定它自己，循环论证） |
| `lsb_to_fs_g()` | 由实测灵敏度反推量程，档位边界取相邻两档的算术中点 |
| `accel_self_calibrate()` | 静止自标定主体：多轮采样 + 静止判定 + 全部失败则回退 |
| `MPU6050_GetAccelLsbPerG()` | 当前实际使用的换算系数 |
| `MPU6050_IsCalibrated()` | 标定是否成功 |

`MPU6050_SelfCheck_t` 新增字段：`cal_ok / cal_retry / fs_cal / cal_lsb /
cal_mean_raw / cal_spread_pct / reg_lsb / fs_used`。

其中 **`fs_cal`（实测反推量程）与 `fs_got`（寄存器声称量程）分开保存**，
这是本版最重要的一处区分：

- `fs_got` = 8g（寄存器在撒谎）
- `fs_cal` = 2g（物理实测）
- `fs_used` = 标定成功取 `fs_cal`，失败取 `fs_got` → `fatal` 判据用它

### 5.2 `user/Inc/user_config.h`

新增总开关（默认开）：

```c
#define MPU6050_AUTOCAL_ENABLE 1
```

置 0 则退回"按寄存器读回值换算"的老行为（复现 3.9 的读数时用）。

### 5.3 阈值连带变化 —— 这是必然的

读数从 ×4 修回真实值，阈值**必须**跟着回到真实量纲：

| 宏 | 上一版 | 现值 | 依据 |
|---|---|---|---|
| `FALL_ACCEL_HIGH_G` | 5.0f | **1.8f** | 受 ±2g 物理上限约束，见下 |
| `FALL_ACCEL_LOW_G` | 4.5f | **1.5f** | 需求原值；静止 1.0 恒小于它，本来就成立 |

**为什么 HIGH 不能是需求原值 2.5**：±2g 档冲击超过 2.0g 即被削顶，读数最高只到
2.0g，2.0 < 2.5 → 条件1 在物理上永不成立。`1.8 < 2.0` 才留出可触发余量。

**这不是取舍，是上限内的唯一选择**（见第 4 节第 ④ 项：2.0 和 2.5 都不可达）。

**如果上一版只把 HIGH 调高、不动 LOW 会怎样**（当时已提示过）：静止 3.9 > 新 HIGH
→ 条件1 满足、进 `IMPACT`，但条件3 要求 < LOW，而 3.9 不小于 1.5 → 永不报警，
现象和没改之前一模一样。**HIGH 和 LOW 必须同向调整**，因为 `|a|` 是三轴模值，
静止时无论帽子怎么翻都恒等于 1g。

### 5.4 显示改动 `user/Src/app_tasks.c` / `user/Src/main.c`

**运行屏 A 行加了模值**（三轴 + `|a|`）：

```
A:1.0 0.0 0.0|1.0
```

这是"换算对不对"唯一的现场凭据 —— 静止时 `|a|` 必须是 1.0。同时它也是"这是加速度
计不是位置传感器"最直接的自证。实现上取 `FallDetect_GetMagnitude()`，即判据真正
使用的那个值，避免"显示用的模值"和"判定用的模值"各算各的。

**自检屏第 5-7 页**改为：

```
MPU 1C w10 r10          ← 寄存器层证据（写进去 0x10、读回来 0x10）
MPU FS 8g->2g !!        ← 量程结论：配置要 8g，【实测】只有 2g，且致命
ACAL 16384 2g s3%       ← 标定详情：实测 16384 LSB/g(±2g)，静置抖动 3%
```

第 6 行右半从"寄存器声称值"改成"**实测值**"是本次的关键修正 —— 旧版这行两处都用
寄存器值，于是克隆片在屏上全绿（`8g->8g OK`），读数却错 4 倍。

**运行屏告警行**新增一种：

| 显示 | 含义 | 怎么办 |
|---|---|---|
| `! MPU6050 FAIL` | 芯片没读到 | 查接线/供电/WHO_AM_I |
| `! FALL DET DISABLED` | 实际量程 ≤ 阈值，冲击削顶 | 换芯片，或把 HIGH 降到量程以内 |
| `! ACAL FAIL` | 上电时没静止，标定没做成 | **保持静止后重启** |

## 6. 现场验证步骤

1. **上电后约 1 秒内不要碰板子** —— 标定要采 64 点（约 190ms），失败会重试。
2. 看自检屏第 7 行：
   - `ACAL 16384 2g sN%` → 标定成功；
   - `ACAL FAIL sN%` → 没静止，重启再来。
3. 进正常显示后看 **A 行末尾的 `|a|`**：
   - `|1.0` → 换算正确，读数可信；
   - `|3.9` → 仍在旧换算下（说明 `MPU6050_AUTOCAL_ENABLE` 被关了，或标定失败了）。
4. **翻转帽子看 `|a|` 是否恒为 1.0** —— 这是"它是加速度计"的直接验证：无论朝哪个
   方向，模值都不变，变的只是三个轴之间的分配。
5. **轻拍帽子**：`|a|` 应撞到约 2.0（±2g 量程顶）→ 状态机进 `IMPACT`，拍两下即报
   `FALL ALARM`（阈值 1.8g，量程顶 2.0g 刚好能过）。
6. **自由落体测试**：从约 1m 落到软垫 —— 下落时 `|a|` 掉向 0（失重），落地瞬间撞到
   2.0，之后静止回到 1.0 → 三条件全过 → 报警 + 蜂鸣 3 秒。

## 8. 遗留限制（必须如实说明）

1. **±2g 是硬伤，软件补不回来。** 真实冲击超过 2g 就被削顶，所有 ≥2g 的冲击读数
   都是同一个 2.0，无法区分"磕一下"（约 2g）与"从 1m 摔下"（约 6g）—— 两者都会
   报警。要恢复需求原设计的 2.5g 阈值，只能换一片**能真正换挡到 ±8g** 的芯片：
   换好后把 `FALL_ACCEL_HIGH_G` 改回 `2.5f` 即可，自标定会自动识别新量程，其余不用动。
2. **标定依赖上电瞬间的静止。** 目前没有运行期复标定机制 —— 失败只能重启。若现场
   确实无法保证上电静止，可考虑加"运行期检测到长时间静止时自动重标"，但需权衡
   "传感器故障输出恒定值被误判为静止"的风险。
3. **不做姿态解算。** 本工程只用 `|a|`，不输出 pitch/roll（`docs/03` 已声明）。
   若要在屏幕上显示倾角，可由 `atan2` 现算：
   `pitch = atan2(ax, √(ay²+az²))`，`roll = atan2(ay, √(ax²+az²))`。
   注意这个算式**天然免疫量程倍数**（分子分母同比例放大，比值不变），但**测不到
   航向 yaw**，那需要磁力计。
4. **角速度未做零偏标定**，仅记录，不参与判据（未变）。

---

## 9. 一句话总结

> 静止时 `|a| ≡ 1g` 是加速度计独有的绝对参考。用它反推灵敏度，既能让读数回到真实 g，
> 也顺带证明了"它测的是加速度而不是位置" —— 位置量不可能在任意姿态下都给出同一个模值。
